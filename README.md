# Rooster Run

A small voxel-style endless runner you can play in the browser. It is inspired by the Chrome dinosaur game, but you play as a chunky rooster: flap over hay bales, fences, corn stalks, and tractor tires, and duck under hawks, scarecrow arms, and low barn beams.

**Play it:** https://nt7s.github.io/rooster-run/

## Controls

- **Jump / flap:** Space, Up arrow, W, or tap (or swipe up)
- **Duck:** Down arrow, S, or swipe down
- You can flap a couple of times in mid-air to stay up a little longer. Flaps refill when you land.
- Speed increases as you run. Your high score is saved in the browser.

Open `index.html` in a modern browser, or serve this folder with any static file server. There is no build step. The game loads [three.js](https://threejs.org/) 0.187.0 from a pinned CDN import map.

The game code was generated with a local Qwen model.
